# MeterGO — GitHub Pages

تطبيق MeterGO لحساب أجرة التاكسي والتوك توك باستخدام GPS، يعمل كموقع HTTPS و Online URL في WebIntoApp.

## خطوات النشر
1. افتح https://github.com/new بالحساب اللي هتستخدمه للنشر.
2. اعمل Repository جديد **Public** واسمه **metergo**، وفعّل Add a README file إن حبيت.
3. فك ضغط MeterGO_GitHub_Pages.zip وارفع **الملفات والمجلدات الموجودة بداخله** إلى جذر المستودع (مش ملف ZIP نفسه، ومش في فولدر فرعي). عند تكرار README.md وافق على استبداله.
4. روح Settings → Pages → Build and deployment واختر Source: Deploy from a branch ثم Branch: main، Folder: /(root) واضغط Save.
5. رابط الموقع غالبًا: `https://USERNAME.github.io/metergo/` (بدّل USERNAME باسم حساب GitHub الفعلي).
6. افتح الرابط على الموبايل، واسمح بصلاحية Location، وبعد الاختبار استخدم الرابط في WebIntoApp كـ Online URL.

**الأسعار الافتراضية المؤقتة:** التاكسي 16.25 جنيه فتح عداد + 5.50 جنيه/كم، التوك توك 7.50 جنيه فتح عداد + 5.00 جنيه/كم. رسوم الانتظار مؤجلة.

**تنبيه:** تتبع GPS على الموقع لا يضمن العمل عند قفل الشاشة أو في الخلفية. يجب اختبار الرحلات الفعلية على أجهزة أندرويد قبل الاعتماد على الأجرة. إعداد اسم وأيقونة تطبيق APK داخل WebIntoApp يتم من واجهة WebIntoApp.
